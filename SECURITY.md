# Security Policy

## Reporting a Vulnerability
- If you discover a security vulnerability, please report it privately to the SCRUM lead (Charles) or email info@metacampus.org.
- Do not disclose vulnerabilities publicly until they have been reviewed and remediated.
- Provide as much detail as possible to help us reproduce and address the issue.

## Security Best Practices
- Never commit secrets, credentials, or sensitive data to the repository.
- Use environment variables for all sensitive configuration.
- Follow the principle of least privilege in all code and infrastructure changes.
- Document known vulnerabilities and mitigations in RISK.md.

## Vulnerability Disclosure
- We will investigate all reported vulnerabilities promptly.
- Once a fix is available, we will coordinate disclosure and remediation with affected parties.

## Contact
- For urgent security issues, contact info@metacampus.org or the SCRUM lead directly.
